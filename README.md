# Vocabulario

Web interactiva para estudiar vocabulario en **inglés británico**, **francés** y **danés** desde el español.

Cada palabra trae imagen, formas (plural o conjugación), pronunciación aproximada, IPA, frase de ejemplo con traducción y botón 🔊 para escucharla (voz del navegador). Tiene tres modos: lista, tarjetas y test.

Incluye los temas básicos (animales, colores, familia, nacionalidades, países, profesiones y números) y la lista Oxford 3000 agrupada por temas, de nivel A1 a B2.
